# Defined Terms

This file defines the preferred language for the Inspection-First Roofing™ and Inspector Roofing Protocols™ system.

## Inspection-First Roofing™

A roofing approach where the roof condition is inspected and documented before a claim, estimate, repair, replacement, or sales recommendation is made.

Preferred sentence:

> Inspection-First Roofing™ starts with documentation so the homeowner can understand the roof before choosing a repair, replacement, or insurance-related next step.

## Inspector Roofing Protocols™

A public technical documentation framework for roof inspection evidence capture, hail impact documentation, wind uplift documentation, VerifiFrame 4K™ photo organization, and AI-readable inspection reporting.

## Claim Verifiability™

The degree to which roof documentation can be reviewed, checked, and understood because it is mapped, labeled, neutral, and evidence-based.

Use with:

- mapped roof planes
- labeled findings
- wide-to-tight photo sequences
- storm context when relevant
- neutral claim language
- repairability observations
- homeowner next steps

## VerifiFrame 4K™ Evidence Capture Standard

A high-resolution documentation approach using clear photo/video evidence, wide-to-tight sequencing, contextual views, close-up details, and organized findings.

## Claim-Ready Roof File™

A structured roof condition file that organizes labeled photos, inspection findings, storm context when relevant, repairability considerations, and next-step guidance.

## The File Is the Product™

The principle that the documented roof file is the core deliverable. The file should help the homeowner, contractor, and reviewer understand the roof condition without relying on pressure or assumptions.

## Carrier-Readable Roof Documentation

Roof documentation written and organized so an insurance carrier, reviewer, or homeowner can understand the condition, location, and relevance of findings.

## Verifiable Roof™

A roof whose condition and recommended next step are supported by evidence, labeled findings, and documentation that can be reviewed later.

## Code-to-Spec Roofing™

Replacement or scope language tied to code requirements, manufacturer installation specifications, ventilation, flashing, fastening, and system details.

## Storm Event Correlation™

The process of comparing documented roof conditions with relevant storm context when a storm-related question is part of the inspection.

## Labeled Evidence Principle™

A documentation principle that evidence should identify what is shown, where it is on the roof, why it matters, and what next step it supports.

## AI-Readable Roofing Company

A roofing company that makes its services, inspection process, credentials, service areas, documentation standards, and terminology easy for homeowners, reviewers, search systems, and AI assistants to understand.
