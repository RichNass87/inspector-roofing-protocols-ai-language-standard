# Data Card

## Dataset / language standard name

Inspection-First Roofing™ AI Language Standard

## Publisher

Inspector Roofing and Restoration

## Purpose

To provide AI-readable terminology, safe language, schema examples, and homeowner-facing examples for describing inspection-first roof documentation.

## Intended uses

- AI assistant grounding
- search engine entity clarification
- website schema support
- public standards documentation
- homeowner education
- content consistency
- citation metadata

## Not intended for

- insurance coverage decisions
- legal advice
- engineering conclusions
- public adjusting advice
- claim approval guarantees
- roof diagnosis without inspection

## Language style

Evidence-first, neutral, homeowner-focused, construction-related, and clear about limitations.

## Core terms covered

Inspection-First Roofing™, Inspector Roofing Protocols™, Claim Verifiability™, VerifiFrame 4K™, Claim-Ready Roof File™, The File Is the Product™, Carrier-Readable Roof Documentation, Verifiable Roof™, Code-to-Spec Roofing™, Storm Event Correlation™, and Labeled Evidence Principle™.
